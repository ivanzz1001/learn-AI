# 如何零基础学习大模型

---

## 1. 视频课程（最推荐零基础先看）

### 1.1 李宏毅《生成式人工智能导论》

- 平台：B站有全集，台大课程官网也有
- 特点：中文讲解，通俗易懂，偶尔吐槽行业乱象，非常接地气。专为零基础设计，重概念、重体
- 适合：完全没接触过AI的人，先建立整体认知

 ### 1.2 Andrej Karpathy 系列视频

- 平台：YouTube原版，B站有翻译版
- 特点：OpenAI创始成员，讲解通俗，对新手超友好。从“什么是语言模型”开始，逐步深入到动手写一个迷你GPT
- 适合：想理解“模型到底在干什么”的人

### 1.3 3. 吴恩达 LLM 系列课程

- 平台：B站、[DeepLearning.AI](https://deeplearning.ai/)
- 特点：经典但节奏偏慢，建议倍速观看。侧重应用和API调用，理论深度适中
- 适合：更想学“怎么用”而不是“怎么造”的人

## 2. 动手实践教程（边跑代码边学）

### 2.1 上海交大《动手学大模型》

- 平台：腾讯云 Cloud Studio 托管，浏览器打开就能跑
- 特点：环境全部配好，不需要显卡，不需要配CUDA。避开枯燥的数学推导，通过代码实战学Prompt、微调、安全攻防
- 适合：完全不想碰环境配置的人

### 2.2 GitHub: LLM-from-scratch

- 平台：GitHub
- 特点：分章节课程，每章有PPT和可运行的Notebook。从Python环境设置开始，逐步推进到注意力机制、GPT实现、预训练、SFT、RLHF
- 适合：有Python基础，想系统跟一遍完整流程的人

### 2.3 Datawhale 理工科大模型入门实训
- 平台：GitHub + 视频课程
- 特点：从API调用到LoRA微调，每章都有视频和实操。明确面向“有基本编程能力、对ML有初步概念”的学习者
- 适合：理工科学生，想边学边做

## 3. 书籍推荐

1. 《从零开始写大模型（从神经网络到Transformer）》
清华大学出版社，王双等著

学习门槛极低，零基础也能轻松掌握。提供配套教学视频、源代码和PPT。第5篇用开源极简模型 MiniMind 带你体验完整构建过程

2. 《大模型技术与构建：从入门到实战（插画版）》
化学工业出版社，逻辑简墨著

用插画形式讲解，从语言起源讲到Transformer架构，再到HuggingFace和LoRA微调。适合被纯文字和公式劝退的人
